# Frontend Resource Intelligence

This directory is the external-resource knowledge layer for HalalFrFr's Frontend Skills.

The canonical dataset is:

- `catalog.csv`
- `catalog.json`

The categorized Markdown files are generated/readable views of that catalog.

## Important

Presence in this catalog does not mean:

- install automatically
- use automatically
- replace project dependencies
- copy visual styles directly

The frontend agent should select resources according to project context and the rules in:

`docs/RESOURCE_POLICY.md`
