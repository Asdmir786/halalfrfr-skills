# Accessible UI Foundations

> Reference catalog for HalalFrFr's Frontend Skills.

| Resource | Tier | Type | Best use | URL |
|---|---|---|---|---|
| shadcn/ui | core | copy-owned component system | Default high-level component source when appropriate; adapt to project design system. | https://ui.shadcn.com |
| Radix UI | core | headless primitives | Accessible React primitives; preserve when existing project uses Radix. | https://www.radix-ui.com |
| Base UI | core | headless primitives | Unstyled accessible primitives; suitable foundation for custom systems. | https://base-ui.com |
| React Aria | core | interaction primitives | High-quality accessible interaction behavior and complex widgets. | https://react-spectrum.adobe.com/react-aria |
| Ariakit | strong | headless primitives | Accessible React primitives and interaction patterns. | https://ariakit.org |
| Ark UI | strong | headless components | Headless components and state-driven UI patterns. | https://ark-ui.com |
| Headless UI | secondary | headless components | Accessible unstyled components, particularly useful in Tailwind ecosystems. | https://headlessui.com |
| Zag.js | secondary | state machines | State-machine patterns for complex interactive components. | https://zagjs.com |
| Floating UI | core | positioning engine | Tooltips, popovers, dropdowns, floating elements and collision-aware positioning. | https://floating-ui.com |
| HeroUI | secondary | component system | Full React UI system; reference or project-specific choice. | https://www.heroui.com |
| Mantine | secondary | component system | Large React component and hooks ecosystem. | https://mantine.dev |
| Chakra UI | secondary | component system | Accessible component system; preserve in existing Chakra projects. | https://chakra-ui.com |
| Material UI | secondary | component system | Mature enterprise Material Design React ecosystem. | https://mui.com |
| Ant Design | secondary | component system | Enterprise-heavy React UI system. | https://ant.design |
| Astryx | watch | design system | Enterprise design-system reference and alternative foundation. | https://github.com/facebook/astryx |
| RetroUI | optional | styled components | Use when the product deliberately needs a retro visual language. | https://retroui.dev |
