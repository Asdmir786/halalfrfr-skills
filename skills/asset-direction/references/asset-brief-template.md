# Asset Brief Template

## Purpose

What must this asset accomplish?

## Placement

Where will it appear?

Examples:

- hero
- section background
- product feature
- card
- interactive stage
- mobile-only composition

## Subject

What specifically appears?

## Composition

Define:

- framing
- focal point
- negative space
- subject position
- camera angle

## Visual Character

Describe:

- realism
- material
- mood
- lighting
- color grade
- depth

## Output

Specify:

- format
- dimensions
- aspect ratio
- transparency
- animation
- loop requirements

## Responsive Requirements

Specify separate crops or safe zones when needed.

## Technical Requirements

Examples:

- maximum practical file size
- alpha channel
- seamless loop
- GLB
- poster frame
- texture limits

## Provenance

Record:

- source
- ownership
- license
- attribution requirements
- generated status
