# Interaction Polish

## Feedback

Every meaningful action should provide timely feedback.

Examples:

- button press
- selection
- expansion
- successful action
- failed action
- loading transition

## Hover

Hover should indicate affordance rather than become a separate visual spectacle.

## Press

Press feedback should generally be fast and small.

## Focus

Keyboard focus should remain clearly visible.

## State Continuity

Transitions should help users understand what changed.

Examples:

- accordion opening from its trigger
- menu appearing from its anchor
- item removal collapsing cleanly
- tab content changing without disorienting motion

## Delay

Avoid unnecessary delays before controls respond.

## Stagger

Use stagger only when sequential reveal improves comprehension or rhythm.

Do not stagger large lists merely because the animation library supports it.

## Motion Distance

Small UI elements usually need small motion distances.

Large travel can make ordinary controls feel slow.

## Principle

Interaction polish should make the interface feel more direct, not more animated.
