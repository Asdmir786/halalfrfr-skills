# Optical Polish

Small visual corrections can improve perceived quality substantially.

## Icons

Inspect apparent rather than only numeric centering.

Some glyphs contain uneven internal whitespace.

## Text and Icons

Check:

- baseline
- vertical center
- gap
- visual weight

A visually heavy icon may need slightly more separation.

## Circular Elements

Circular badges and avatar controls may appear vertically different from square controls despite identical dimensions.

Inspect them in context.

## Typography

Capital letters, numerals, and punctuation may create optical imbalance.

Avoid excessive manual offsets.

Use small corrections only when the imbalance is visibly persistent.

## Logos

Do not assume the visible artwork fills the SVG viewBox.

Align the visible mark, not merely its file bounds.

## Principle

Use optical correction to improve perception, not to create a collection of unexplained magic numbers.
