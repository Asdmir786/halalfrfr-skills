# Provenance and Scope

Studying a public interface does not grant ownership of its assets or source code.

## Safe Extraction Focus

Extract concepts such as:

- spacing
- typography behavior
- hierarchy
- color roles
- component anatomy
- responsive patterns
- motion principles

## Avoid Copying

Do not redistribute or reproduce third-party:

- logos
- photography
- illustrations
- proprietary fonts
- source code
- trademarked visual assets

without appropriate rights.

## User-Owned Sources

When the user owns or provides the source material, follow the user's requested fidelity while still respecting any explicit constraints.

## Documentation

When provenance matters, record whether a decision came from:

- project source
- user-provided reference
- public visual observation
- inference
