# Design-System Extraction Checklist

## Color

Record recurring roles:

- background
- foreground
- surface
- muted
- border
- accent
- semantic states

## Typography

Record:

- family
- scale
- weight
- line height
- tracking
- measure

## Spacing

Record recurring:

- internal spacing
- group spacing
- grid gaps
- gutters
- section spacing

## Layout

Record:

- page width
- text width
- columns
- grid behavior

## Surfaces

Record:

- radius
- border
- shadow
- tonal hierarchy

## Components

Record recurring anatomy and variants.

## Responsive

Record visible transformations.

## Motion

Record only observable motion behavior.

## Confidence

Mark whether the observation is:

- explicit
- strong
- inferred
- uncertain
