# Responsive QA

Do not rely only on named framework breakpoints.

## Useful Viewport Classes

Test representative examples of:

- narrow mobile
- normal mobile
- large mobile or small tablet
- tablet
- small laptop
- normal laptop or desktop
- wide desktop when relevant

Exact dimensions may depend on the project.

## Also Test

- short viewport height
- long content
- long labels
- empty states
- error messages
- loading states
- keyboard focus
- touch interaction
- overflow
- zoom when relevant

## Visual Checks

Look for:

- accidental horizontal scrolling
- clipped text
- overlapping controls
- awkward line breaks
- broken sticky elements
- media focal-point loss
- excessive blank space
- content hidden behind fixed UI

## Principle

The goal is not screenshot perfection at a few widths.

The goal is stable composition throughout the meaningful range between them.
