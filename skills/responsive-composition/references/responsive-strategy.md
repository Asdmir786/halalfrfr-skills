# Responsive Strategy

## Preserve

Across viewports preserve:

- task priority
- message priority
- brand character
- interaction meaning
- information relationships

Do not preserve exact coordinates.

## Ask Per Region

For every major region ask:

- must it remain visible?
- can it move?
- can it stack?
- can it simplify?
- can it become progressive?
- does it need a different crop?
- does it need a different interaction?

## Breakpoint Trigger

Create or use a breakpoint when a relationship fails.

Examples:

- two columns become unreadable
- controls collide
- heading wraps poorly
- chart labels overlap
- navigation overflows

## Content Priority

Classify content:

1. critical
2. important
3. supporting
4. decorative

Responsive simplification should normally begin at the bottom of that list.

## Same Product, Different Composition

A responsive version can look substantially different while remaining faithful if hierarchy, identity, and task intent are preserved.
