# Semantic HTML and Keyboard

## Native Elements

Prefer native controls.

They provide built-in semantics and expected interaction.

## Buttons

Use for actions.

Keyboard activation should follow native behavior.

## Links

Use for navigation.

## Headings

Represent document hierarchy.

## Lists

Use for actual grouped list content.

## Tables

Use for tabular relationships.

## Keyboard Review

Test logical navigation with:

- Tab
- Shift+Tab
- Enter
- Space where applicable
- Escape where applicable
- arrow keys where the widget pattern requires them

## Principle

Do not recreate browser behavior with generic elements unless there is a strong reason.
