# WCAG-Oriented Workflow

## Baseline

Use WCAG 2.2 unless project requirements specify another standard.

## Automated Review

Run available accessibility tooling.

Treat findings as inputs, not final proof.

## Manual Review

Inspect:

- semantics
- keyboard
- focus
- labels
- headings
- errors
- responsive order
- contrast
- motion

## Functional Review

Complete important user flows without a mouse.

## Remediation

Prioritize issues that:

- block tasks
- hide information
- prevent navigation
- create severe confusion

## Re-Test

Verify the corrected interaction.

## Compliance Claims

Do not claim full WCAG compliance solely from automated testing.

Formal compliance may require broader expert and legal review.
