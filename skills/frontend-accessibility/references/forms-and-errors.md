# Forms and Errors

## Labels

Every meaningful form field should have a programmatic label.

Placeholder text is not a replacement for a label.

## Instructions

Provide instructions before users need them when the requirement is not obvious.

## Errors

Explain:

- what is wrong
- where it is wrong
- how to recover when practical

Associate field-level errors with their fields.

## Required

Communicate required fields clearly.

## Grouping

Related controls may need semantic grouping.

## Submission

Communicate:

- submitting
- success
- failure

Do not allow repeated submissions accidentally when that would create harmful duplicate actions.

## Principle

A form should remain understandable without relying on color or visual proximity alone.
