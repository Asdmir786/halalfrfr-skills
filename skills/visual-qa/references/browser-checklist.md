# Browser Visual Checklist

Inspect relevant:

- page load
- layout
- typography
- images
- icons
- controls
- overflow
- sticky elements
- fixed elements
- modal layers
- menus
- loading state
- error state
- mobile navigation
- console errors

## Interaction

Where relevant inspect:

- hover
- focus
- open
- selected
- disabled
- pressed

## Media

Confirm:

- correct file
- crop
- aspect ratio
- focal point
- fallback

## Responsive

Move through the meaningful width range rather than checking only breakpoint endpoints.

## Principle

Rendered behavior is the source of truth for visual QA.
