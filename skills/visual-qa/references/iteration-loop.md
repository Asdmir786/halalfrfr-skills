# Visual QA Iteration Loop

## Render

Capture the current implementation.

## Inspect

Identify the largest visible issue.

## Diagnose

Determine whether the cause is:

- structure
- width
- spacing
- typography
- asset
- responsive rule
- component style
- motion state

## Change

Apply the smallest coherent correction.

## Re-Render

Capture the same viewport and state again.

## Compare

Confirm the intended defect improved without creating another regression.

## Repeat

Continue with the next highest-impact issue.

## Principle

Controlled iteration converges faster than random visual tweaking.
