# Visual Defect Taxonomy

## Critical

Blocks use or destroys layout.

Examples:

- content inaccessible
- major overlap
- navigation broken
- severe overflow

## Major

Strongly harms visual quality or hierarchy.

Examples:

- wrong layout proportions
- wrong responsive composition
- incorrect media crop
- large spacing error
- wrong typography scale

## Moderate

Noticeable inconsistency.

Examples:

- control sizes
- surface inconsistency
- alignment problems
- weak state styling

## Minor

Low-impact polish difference.

Examples:

- subtle shadow
- small radius mismatch
- optical icon alignment

## Principle

Fix higher-severity defects before minor polish.
