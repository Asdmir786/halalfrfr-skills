# Composition and Hierarchy

## Focal Hierarchy

Every viewport should have an obvious reading order.

Control hierarchy with:

- scale
- contrast
- position
- whitespace
- density
- image dominance
- type weight
- color
- motion

Do not use all mechanisms at once.

## Page Rhythm

Strong experiences usually alternate between different visual pressures.

Examples:

dense
→ spacious

quiet
→ dramatic

text-led
→ image-led

static
→ interactive

light
→ dark

Use contrast intentionally.

## Section Composition

Avoid making every section:

heading
paragraph
three cards

Possible composition families include:

- editorial split
- full-bleed media
- oversized typography
- anchored content with floating visual
- image sequence
- product demonstration
- horizontal narrative
- asymmetrical grid
- dense information field
- interactive stage
- focused single statement

The page may use multiple families as long as one visual system connects them.

## Typography

### Display type

Use for:

- concept
- identity
- major transitions
- emotional character

### Functional type

Use for:

- body copy
- labels
- data
- forms
- controls

One family may perform both roles if its range supports it.

## Line Length

Do not let text containers become narrow merely to create dramatic wrapping.

Body copy should remain comfortably readable.

Display copy may use controlled line breaks when the composition benefits.

## Scale

Large typography should have a purpose.

Scale may establish:

- confidence
- drama
- editorial hierarchy
- visual anchor

Do not make text large simply because the hero feels empty.

## Whitespace

Whitespace is structural.

Use it to:

- separate ideas
- create tension
- emphasize
- slow pacing
- establish hierarchy

Do not confuse whitespace with unused space.

## Density

Application interfaces may require higher density than marketing pages.

High density can still feel premium when:

- alignment is strong
- typography is disciplined
- grouping is clear
- controls are consistent
- spacing relationships are predictable

## Alignment

Use a deliberate alignment system.

Avoid accidental near-alignment.

Optical alignment may differ slightly from mathematical alignment when visual balance requires it.

## Overlap

Overlap can create:

- depth
- continuity
- tension
- visual connection

Do not overlap important content if it harms readability or responsiveness.
