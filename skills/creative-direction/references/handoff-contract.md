# Creative Direction Handoff Contract

When another skill needs the result of creative direction, provide or internally maintain the following decisions.

## Visual Thesis

One sentence describing the core visual idea.

## Interface Type

One of:

- marketing
- product
- hybrid

## Audience

Who must understand, trust, desire, or use the interface.

## Emotional Target

Two or three intentional qualities.

## Dominant Visual Device

Examples:

- typography
- photography
- product imagery
- spatial composition
- data
- video
- 3D

## Composition

Describe:

- grid behavior
- alignment
- density
- section rhythm
- focal hierarchy
- whitespace behavior

## Typography

Describe:

- display character
- body character
- scale contrast
- line-length behavior
- weight behavior

## Color

Describe:

- primary field
- secondary field
- accent behavior
- semantic color behavior when applicable

## Surface

Describe:

- flat or dimensional
- border behavior
- elevation behavior
- radius behavior
- material character

## Asset Requirements

List only assets actually needed.

## Motion Character

Describe the motion personality before implementation technology.

## 3D Position

Choose one:

- unnecessary
- optional enhancement
- useful
- central to concept

Explain why if useful or central.

## Responsive Priorities

State what must remain visually dominant on:

- desktop
- tablet
- mobile

## Constraints

Record:

- brand constraints
- existing-system constraints
- technical constraints
- accessibility-sensitive decisions
- performance-sensitive decisions

## Downstream Routing

Use the relevant specialist skills:

- design-system-web
- asset-direction
- responsive-composition
- advanced-motion
- web-3d
- frontend-architecture
- frontend-ui-engineering
- visual-qa

Do not make the creative-direction skill perform specialist implementation work itself.
