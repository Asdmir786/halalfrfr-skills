# Natural Language Examples

The user can say:

- `start a SaaS for dental clinic follow-ups, ask me what matters`
- `make this dashboard clean, less AI looking, and easier for managers`
- `add roles and make sure one company cannot see another company's data`
- `use this HTML as reference but rebuild it properly in Next`
- `the frontend is Vercel and Laravel is on my server, wire it correctly`
- `refactor this mess without changing how it works`
- `use shadcn, but don't leave it looking default`
- `check security and fix only real high-risk issues`
- `upgrade the stack safely to current stable versions`

The agent translates these into inspection, questions only where needed, specialist routing, implementation, and verification. The user does not need to use headings such as Goal, Context, Constraints, or Done When.
