# Visual Analysis

Analyze the reference from large structure to small detail.

## 1. Page Frame

Identify:

- page background
- maximum content width
- gutters
- major vertical sections

## 2. Major Composition

Identify:

- columns
- alignment anchors
- media regions
- overlaps
- dominant focal point

## 3. Typography

Identify:

- display hierarchy
- body hierarchy
- label hierarchy
- line breaks
- text width

## 4. Components

Identify:

- buttons
- inputs
- navigation
- cards
- tabs
- tables
- badges

## 5. Surfaces

Identify:

- border
- shadow
- radius
- elevation
- transparency

## 6. Assets

Identify which visuals require real assets rather than CSS recreation.

## 7. Detail

Only after the macro structure is correct inspect:

- icon spacing
- subtle borders
- exact radii
- micro-alignment

## Principle

Fix the largest structural mismatch first.
