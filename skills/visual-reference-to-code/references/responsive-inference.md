# Responsive Inference From Visual References

A desktop screenshot does not define mobile automatically.

## Preserve

Preserve:

- primary message
- primary task
- dominant visual
- brand character
- information relationships

## Infer

Determine:

- what stacks
- what reorders
- what simplifies
- what becomes scrollable
- what changes crop
- what moves into an overflow or drawer

## Existing Product

Prefer the existing responsive patterns of the project.

## Multiple Screenshots

If multiple widths are supplied, derive the transformation rules between them.

## Unsupported Detail

When the reference does not reveal a responsive behavior, choose the simplest conventional behavior that preserves meaning.

Do not invent a highly novel mobile interaction without evidence.
