# Fidelity Workflow

## Baseline

Capture the current implementation before major changes when working in an existing project.

## Build

Implement the largest structural relationships first.

## Render

Capture the target viewport.

## Compare

Ask:

- what looks most different?
- is the problem structural or decorative?
- is the mismatch caused by typography?
- is the mismatch caused by media crop?
- is the mismatch caused by container width?

## Fix

Correct the underlying cause.

## Repeat

Continue until remaining differences are low-impact or intentional.

## Do Not

Avoid changing many unrelated values at once.

That makes it difficult to identify which change improved or harmed fidelity.

## Principle

Visual fidelity should improve through controlled comparison, not guesswork.
