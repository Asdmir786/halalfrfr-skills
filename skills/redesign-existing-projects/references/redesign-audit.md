# Redesign Audit

Review the interface before proposing changes.

## Hierarchy

Check:

- focal point
- reading order
- primary action
- information priority

## Typography

Check:

- scale
- weight
- line height
- line length
- consistency

## Layout

Check:

- alignment
- containers
- density
- rhythm
- whitespace

## Components

Check:

- consistency
- states
- visual language
- duplicated patterns

## Responsive

Check real behavior at multiple sizes.

## Product States

Check:

- loading
- empty
- error
- long content
- dense content

## Interaction

Check:

- hover
- focus
- press
- feedback

## Principle

Identify the cause of weak quality before choosing the redesign technique.
