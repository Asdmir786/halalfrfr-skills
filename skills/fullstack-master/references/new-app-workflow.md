# New Application Workflow
1. Read idea/PRD.
2. Audit requirements.
3. Define actors, flows, rules.
4. Propose architecture.
5. Define data/auth/contracts.
6. Define frontend/backend plan.
7. Present approval brief.
8. Build foundation.
9. Implement vertical slices.
10. Verify critical flows.
11. Reconcile docs.

Prefer vertical slices that prove contracts over building every backend endpoint before any usable product slice.
