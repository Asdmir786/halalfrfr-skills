# Existing Application Workflow
1. Inspect repository/current behavior.
2. Identify contracts and critical flows.
3. Audit frontend/backend/data/auth/integrations.
4. Classify KEEP / REFACTOR / REPLACE / MIGRATE.
5. Propose target/blast radius.
6. Present approval brief.
7. Implement incrementally after approval.
8. Verify after each meaningful phase.
9. Update docs to match actual architecture.
