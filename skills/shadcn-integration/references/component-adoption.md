# shadcn Component Adoption

## Before Adding

Search existing source.

Check whether:

- component already exists
- wrapper exists
- domain component already solves the problem

## When Adding

Review:

- dependencies
- component base
- aliases
- styling
- accessibility
- external packages

## After Adding

Adapt:

- tokens
- variants
- typography
- density
- visual language

## Existing Components

Treat them as project-owned source code.

Do not overwrite local customization without inspection.

## Registries

Registry code may require:

- dependency review
- license review
- visual adaptation
- accessibility review

## Principle

Add components to solve product requirements, not to grow a component collection.
