# Project Memory

These files are maintained by the AI software director and repository agents:

- `../PRODUCT.md` — product and business truth
- `UX.md` — users, workflows, permissions, routes, and states
- `../DESIGN.md` — visual and interaction direction
- `UI_SYSTEM.md` — reusable interface implementation rules
- `ARCHITECTURE.md` — system modules, boundaries, deployment, and operations
- `DATA_API.md` — data ownership, schemas, API contracts, events, and migrations
- `SECURITY.md` — auth, tenancy, privacy, threats, and sensitive operations
- `QUALITY.md` — verification, accessibility, performance, and release gates

Create feature briefs under `features/` only for important cross-layer behavior. Create ADRs under `decisions/` only for durable architectural choices.
