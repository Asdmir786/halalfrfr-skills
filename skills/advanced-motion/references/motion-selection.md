# Motion Selection

## CSS

Prefer for:

- simple hover
- focus transition
- small opacity change
- simple transforms
- uncomplicated state changes

## Component Motion Library

Prefer for:

- enter and exit
- shared layout transitions
- gestures
- component-state animation
- ordinary React micro-interactions

## GSAP

Prefer for:

- coordinated timelines
- complex sequencing
- pinned stories
- advanced scroll progression
- multiple synchronized targets
- high-control marketing experiences

## WebGL

Prefer when the animation requires:

- shaders
- spatial rendering
- real-time 3D
- large numbers of GPU-driven visual objects

## Decision Rule

Use the lowest-complexity tool that preserves the desired experience.

Tool choice should follow the design, not define it.
