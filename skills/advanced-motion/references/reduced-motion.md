# Reduced Motion

Reduced motion is an alternate presentation of the same information.

## Preserve

Always preserve:

- content
- interaction
- state
- hierarchy
- navigation
- task completion

## Simplify

Possible strategies:

- remove parallax
- remove large travel
- disable scrub
- disable pinning
- replace movement with opacity
- shorten transitions
- show the final state immediately
- replace real-time animated background with static media

## Product Demonstrations

If animation explains a process, provide a representation that still communicates the process.

Do not simply hide the demonstration.

## Principle

Reduced motion is not a degraded product.

It is a less motion-intensive rendering of the same experience.
