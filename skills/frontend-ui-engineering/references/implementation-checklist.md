# Frontend Implementation Checklist

## Before

- inspect project conventions
- identify existing reusable components
- identify design-system rules
- understand requested behavior
- understand existing behavior that must remain

## During

- keep responsibilities clear
- maintain one source of truth
- avoid unnecessary effects
- use project primitives
- implement interaction states
- implement responsive behavior
- preserve semantic markup
- avoid unnecessary dependencies

## After

- type check
- lint when configured
- run relevant tests
- inspect runtime console
- test interaction paths
- inspect responsive layouts
- perform visual QA

## Existing Project

Confirm that unrelated behavior did not change.

## New Project

Confirm that implementation establishes patterns future sections can follow without excessive abstraction.
